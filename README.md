# S.T.A.L.K.E.R. 2 Loadout Creator

Візуальний редактор loadouts NPC у S.T.A.L.K.E.R. 2. Дозволяє налаштувати предмети, які отримує НІП при спавні, замість ручного редагування довгого CFG-файлу.

Користувач редагує списки предметів за категоріями для `Faction_Class` та їхні відносні ваги для чотирьох рангів гравця: Novice (у поточному коді — Newbie), Experienced, Veteran, Master. Можна обирати готові пресети та ділитися власними.

Фронтенд генерує CFG і завантажує його в ZIP. Бекенд `s2-loadout-creator-rest` зберігає та завантажує пресети через REST API, а також пакує CFG у PAK.

Сайт: [dev.s2-loadout-creator.cc](https://dev.s2-loadout-creator.cc/).

## Локальна розробка

Власний код застосунку, інтеграцій, тестів, скриптів і конфігурацій написаний на TypeScript. Стек: Vite, Bootstrap, JSZip. Редактор підтримує незалежну базу, порівняння та локальний reset.

Підтримуваний і перевірюваний runtime — Node 26.10.0 (також використовується в CI). Тести й скрипти запускають TS через вбудовану підтримку Node; ESLint використовує native TS config flag. Встановлення з lockfile:

```sh
npm ci
npm run dev
```

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Локальний сервер на порту 3000 або PORT |
| `npm run check:sources` | Інвентар усього репозиторію: відсутність власного JS/inline JS, охоплення всіх TS-файлів |
| `npm run typecheck` | Інвентар і strict-перевірки застосунку, тестів та tooling |
| `npm run lint` | ESLint для застосунку, тестів, скриптів та конфігурацій |
| `npm test` | Локальні JSON/CFG/ZIP, DOM і підмінені REST-контракти |
| `npm run build` | Та сама повна команда typecheck, потім production Vite build |
| `npm run preview` | Перегляд dist |

CI виконує `npm ci`, lint, тести та build (включно з typecheck). Автоматичні перевірки не потребують реального бекенду. Для ручної локальної перевірки: змінити вагу, перейти між категоріями, перевірити diff/reset, експортувати JSON, імпортувати його та завантажити ZIP. В архіві має бути `Stalker2/Content/GameLite/GameData/ItemGeneratorPrototypes/New_NPC_Loadouts.cfg`.

`VITE_RESTUrl` налаштовує чинні серверні інтеграції (див. `.env.example`). Для автономної перевірки не використовуйте серверний CRUD або PAK. Успішні локальні тести не підтверджують серверне PAK-пакування, живі пресети чи поведінку в грі.

Відомі обмеження: Edit preset зберігає поточну конфігурацію редактора; прихована кнопка Update має попередню помилку відсутнього handler; результат операції без error, навіть result:false, зберігає попередню UI-семантику. F15 збережено адаптером: PAK використовує fallback-ім'я. Їх функціональні виправлення не входять до TS-міграції. У збірці залишаються Sass deprecation warnings Bootstrap; подробиці перевірок — у [tests/README.md](tests/README.md).
